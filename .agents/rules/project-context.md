# Project Context & Business Logic

## 1. Goal of "Outreach"
The system is designed to automate the initial stages of B2B client acquisition. It minimizes the manual effort required to find leads, evaluate their potential, and write the first contact message.

## 2. Core Entities
- **Lead / Business:** A company found on Google Maps. We care about their Name, Rating, Review Count, Phone, Website, and Category.
- **Score:** An AI-generated metric (0-100) determining how likely this lead needs our services (e.g., if their website is bad or reviews are low).
- **Outreach Message:** A hyper-personalized WhatsApp message generated by AI, referencing their specific business details or recent reviews.

## 3. The "Ideal" Lead
When building the AI scoring mechanism, keep in mind that the system favors leads that:
- Have a valid phone number (preferably WhatsApp-able).
- Have a website that might need improvement (or no website at all).
- Have enough reviews to be an established business, but perhaps some negative reviews we can help them address.

## 4. Agent Guidelines on Context
Whenever you are writing a prompt for LiteLLM or designing the Dashboard UI, prioritize making the "Score" and the "Generated Message" the most prominent features. The user's main action on the dashboard will be reviewing the AI's generated message and clicking "Send via WhatsApp".
